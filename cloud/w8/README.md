Tuần 8 tập trung vào nền tảng Terraform và Kubernetes.


## Lịch học

- T2 01/06: Terraform phần 1 - tổng quan IaC, cú pháp HCL, workflow cơ bản.
- T3 02/06: Kubernetes self-study - Pod, Service, probes, ConfigMap, Secret, NetworkPolicy. Cài Docker Desktop, kubectl, minikube.
- T4 03/06: Terraform phần 2 - state, modules, best practices, ADR. Live session và Online Test 1.
- T5 04/06: Onsite Kubernetes lab trên minikube.
- T6 05/06: Hoàn thiện lab, show-and-tell, Online Test 2.
