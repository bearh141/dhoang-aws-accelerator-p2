# Lab - Mini K8s Platform Trên Minikube

## Mục tiêu

Xây một Kubernetes platform tối giản trên máy local bằng minikube.

## Evidence cần có

- `minikube status`
- `kubectl get nodes`
- `kubectl get pods`
- `kubectl get svc`
- Screenshot hoặc command output chứng minh truy cập được application
- Ghi chú ngắn cho phần show-and-tell

## Ghi chú

Thêm manifest và evidence của lab tại đây.
